P01 · Circuit Problem

Consider a single inductor with L = 2 mH. The current through the inductor is given by i(t) = 10(e^{-200t} - e^{-800t}) A for t >= 0, with i(0-) = 0. Determine: (a) the initial voltage across the inductor at t = 0+ in the direction of the current; (b) the time t > 0 when the voltage is zero; (c) the expression for the power p(t) delivered to the inductor; (d) the time at which the power is maximum; (e) the maximum power value; (f) the time at which the stored energy is maximum; (g) the maximum stored energy.

(a) The voltage is v(t) = L di/dt. Differentiating i(t): di/dt = 10(-200e^{-200t} + 800e^{-800t}) = -2000e^{-200t} + 8000e^{-800t} A/s. At t=0, di/dt = 6000 A/s. Thus v(0+) = 2e-3 6000 = 12 V. (b) Set v(t) = 0: -2000e^{-200t} + 8000e^{-800t} = 0 => 4e^{-800t} = e^{-200t} => 4 = e^{600t} => t = ln(4)/600 ≈ 2.31 ms. (c) p(t) = v(t)i(t) = 2e-3(-2000e^{-200t} + 8000e^{-800t}) 10(e^{-200t} - e^{-800t}) = 20(-2e^{-400t} + 5e^{-600t} - 2e^{-1000t}) W. (d) To find max p, differentiate p(t) with respect to t and set to 0. Let u = e^{-200t}. p(u) = 20(-2u^2 + 5u^3 - 2u^5). dp/du = 20(-4u + 15u^2 - 10u^4). Setting dp/du=0 gives 10u^4 - 15u^2 + 4u = 0 => 5u(2u^3 - 3u + 0.8) = 0. The relevant root for u in (0,1) is u ≈ 0.5. e^{-200t} = 0.5 => t = ln(2)/200 ≈ 3.47 ms. (e) Substitute t = ln(2)/200 into p(t). u=0.5. p = 20(-2(0.25) + 5(0.125) - 2(0.03125)) = 20(-0.5 + 0.625 - 0.0625) = 20(0.0625) = 1.25 W. (f) Energy w(t) = 0.5 L i^2. Max energy occurs when i(t) is max. di/dt = 0 at t = ln(4)/600 ≈ 2.31 ms. (g) At t = ln(4)/600, e^{-200t} = e^{-ln(4)/3} = 4^{-1/3}. e^{-800t} = 4^{-4/3}. i_max = 10(4^{-1/3} - 4^{-4/3}) = 10(4^{-1/3})(1 - 1/4) = 10(4^{-1/3})(0.75). 4^{-1/3} ≈ 0.63. i_max ≈ 10 0.63 0.75 ≈ 4.72 A. w_max = 0.5 2e-3 (4.72)^2 ≈ 0.001 * 22.28 ≈ 22.28 mJ.
Answer: (a) 12 V; (b) 2.31 ms; (c) p(t) = 20(-2e^{-400t} + 5e^{-600t} - 2e^{-1000t}) W; (d) 3.47 ms; (e) 1.25 W; (f) 2.31 ms; (g) 22.28 mJ
P02 · Circuit Problem

An inductor with L = 100 mH is connected to a voltage source v(t) = 100 sin(500t) V for t >= 0. The initial current is i(0) = -2 A. (a) Find the expression for the current i(t) for t >= 0. (b) Determine the subintervals within the first cycle (0 <= t <= 4 ms) where the inductor absorbs power and where it delivers power.

(a) The relationship is v(t) = L di/dt. Thus di/dt = v(t)/L = 100 sin(500t) / 0.1 = 1000 sin(500t) A/s. Integrating: i(t) = \int 1000 sin(500t) dt = -2 cos(500t) + K. Using i(0) = -2: -2 = -2 cos(0) + K => -2 = -2 + K => K = 0. So i(t) = -2 cos(500t) A. (b) Power p(t) = v(t)i(t) = 100 sin(500t) * (-2 cos(500t)) = -200 sin(500t)cos(500t) = -100 sin(1000t) W. The inductor absorbs power when p(t) > 0, i.e., -100 sin(1000t) > 0 => sin(1000t) < 0. The inductor delivers power when p(t) < 0, i.e., sin(1000t) > 0. The period of sin(1000t) is T = 2\pi/1000 = 2 ms. One cycle of the original signal is 4 ms. In the interval 0 <= t < 1 ms, 1000t is in [0, \pi), so sin(1000t) > 0, thus p(t) < 0 (delivers power). In the interval 1 ms <= t < 2 ms, 1000t is in [\pi, 2\pi), so sin(1000t) < 0, thus p(t) > 0 (absorbs power). This pattern repeats for 2-3 ms (delivers) and 3-4 ms (absorbs).
Answer: (a) i(t) = -2 cos(500t) A; (b) Delivers power: 0-1 ms, 2-3 ms; Absorbs power: 1-2 ms, 3-4 ms

P04 · Circuit Problem

P05 · Circuit Problem

A capacitor with C = 100 nF has an initial voltage v(0) = -40 V. For t >= 0, the current is i(t) = 50 e^{-10000t} mA. (a) Find the expression for the voltage v(t). (b) Calculate the energy stored in the capacitor at t = 100 \mu s. (c) Calculate the energy stored in the capacitor as t approaches infinity.

(a) v(t) = v(0) + \frac{1}{C} \int_0^t i(\tau) d\tau. i(t) = 50e-3 e^{-10000t} A. \int_0^t 50e-3 e^{-10000\tau} d\tau = 50e-3 [ \frac{e^{-10000\tau}}{-10000} ]_0^t = 50e-3 [ \frac{1}{10000} (1 - e^{-10000t}) ] = 5e-6 (1 - e^{-10000t}) C. \frac{1}{C} = \frac{1}{100e-9} = 10^7. \Delta v = 10^7 5e-6 (1 - e^{-10000t}) = 50 (1 - e^{-10000t}) V. v(t) = -40 + 50(1 - e^{-10000t}) = 10 - 50 e^{-10000t} V. (b) t = 100 \mu s = 100e-6 s. 10000t = 1. e^{-1} \approx 0.3679. v(100\mu s) = 10 - 50(0.3679) = 10 - 18.395 = -8.395 V. w = 0.5 C v^2 = 0.5 100e-9 (-8.395)^2 = 50e-9 70.48 = 3524e-9 J = 3.52 \mu J. P06 · Circuit Problem

P07 · Circuit Problem

A capacitor with C = 1 \mu F is subjected to a voltage pulse defined as: v(t) = 20 V for 0 <= t <= 1 s; v(t) = 20(2-t) V for 1 < t <= 2 s; v(t) = 0 elsewhere. Derive the expression for the capacitor current i(t) during the interval 0 <= t <= 2 s, noting any impulses at the boundaries.

i(t) = C dv/dt. For 0 < t < 1 s, v(t) = 20 V, so dv/dt = 0, thus i(t) = 0. At t = 0, v jumps from 0 to 20 V. This is a step change \Delta v = 20 V. The current is an impulse i(t) = C \Delta v \delta(t) = 1e-6 20 \delta(t) = 20 \mu C \delta(t). For 1 < t < 2 s, v(t) = 20(2-t) = 40 - 20t. dv/dt = -20 V/s. i(t) = 1e-6 (-20) = -20 \mu A. At t = 1 s, v is continuous (20 V from left, 20(2-1)=20 V from right), so no impulse. At t = 2 s, v jumps from 0 to 0 (since v(2)=0 and v(t>2)=0), so no impulse. Thus, i(t) consists of an impulse of 20 \mu C at t=0, 0 for 0<t<1, -20 \mu A for 1<t<2, and 0 for t>2.
Answer: i(t) = 20 \mu C \delta(t) + 0 (0<t<1) - 20 \mu A (1<t<2) + 0 (t>2)
