1 What is linear waveshaping?

Linear waveshaping is the process whereby the shape of a non-sinusoidal signal is altered by transmission through a linear network. We study how step, pulse, square, ramp and exponential waveforms come out of simple RC circuits — and this lecture’s two workhorses are:

High-pass RC

Output taken across the resistor. Passes fast changes, blocks DC.

Low-pass RC

Output taken across the capacitor. Passes slow/DC, blocks fast changes.

2 The high-pass RC circuit

High-pass: series C, shunt R.

For sinusoidal input (preview of Laplace territory), the transfer function has:

\(\omega_c = \dfrac{1}{RC}\)lower 3-dB frequency
\(\left|\dfrac{v_o}{v_i}\right| = \dfrac{\omega RC}{\sqrt{1+\omega^2R^2C^2}}\)
👀 Phase: output leads input

The HP output leads the input by \( \theta = \arctan\!\big(\dfrac{1}{\omega RC}\big) \), approaching 90° at high frequency. (Full frequency response returns with Laplace later — the slides note exactly that. 🙂)

3 HP · step voltage input

Apply a step \( v_{in} = V\,u(t) \). Steady-state (DC) analysis says the capacitor ends up an open, so no final current flows and the final output is zero. The 4-step procedure gives:

(5.1) \[ v_o(0^+) = V \quad(\text{C uncharged ⇒ short ⇒ all of } V \text{ across } R) \] \[ \boxed{\;v_o(t) = V\,e^{-t/\tau}\;}, \qquad \tau = RC, \qquad t \ge 0 \] The output jumps to V at t = 0 and decays to zero — the mirror image of the LP step.

4 HP · pulse input

With \( v_{in} = V_p[u(t) - u(t-t_p)] \), the output is again two intervals — same method as Lecture 4, now with \( v_o = v_{in} - v_C \):

0 < t < tₚ \[ v_o(t) = V_p\,e^{-t/\tau} \]
t > tₚ \[ v_o(t) = -V_p\left(1 - e^{-t_p/\tau}\right)e^{-(t-t_p)/\tau} \]

At the falling edge the output jumps down by exactly Vp (same size, opposite direction as the input jump) and decays back toward zero from below. The pulse is “centered” around zero DC — previewing the HP’s DC-blocking character.

5 HP behavior · three rules to memorize

① DC block

The average level of the output is always zero. Any DC component in the input is removed — the output swings around 0 V.

② Edge copying

Whenever the input changes discontinuously by \( \Delta V \), the output changes discontinuously by the same amount, in the same direction — the capacitor voltage can’t jump, so the whole jump appears across R.

③ Exponential decay to zero

During any finite interval where the input holds a constant level, the output decays exponentially toward zero with time constant RC.

🎯 These three rules draw any HP waveform

Sketch the input, copy every edge 1:1, then draw a decay toward 0 between edges. No algebra needed — the interactive lab below does exactly this for you.

6 HP as a differentiator

When \( RC \) is very small compared with the time over which the input can make an appreciable change, the output barely decays between edges — and the math collapses to:

(5.2) \[ v_o(t) = v_{in}(t) - v_C(t), \qquad v_C(t) = \frac{1}{RC}\int_{-\infty}^{t} v_{in}(\lambda)\,d\lambda \] With τ = RC very small, v_C stays tiny and the output is a narrow spike at every edge — its area is ΔV·RC, exactly the area of RC times the impulse that is d v_in/dt.
\[ \boxed{\;v_o(t) \;\approx\; RC\,\frac{d\,v_{in}(t)}{dt}\;} \qquad \left(\tau = RC \ll \frac{T}{2}\right) \] The HP circuit is a differentiator in the small-RC limit.
📐 What that means in practice

A square wave in gives spikes out (huge at edges, zero between) — the classic differentiator waveform. Condition: \( \tau \ll T/2 \) (small RC relative to the signal period). The mirror condition \( \tau \gg T/2 \) makes the LP an integrator — next.

7 The low-pass RC circuit

Low-pass: series R, shunt C.

With sinusoidal input, the upper 3-dB frequency is again \( \omega_c = 1/(RC) \), but now the response falls off above it:

\[ \left|\frac{v_o}{v_i}\right| = \frac{1}{\sqrt{1+\omega^2R^2C^2}}, \qquad \theta = -\arctan(\omega RC) \] Output lags input by θ; at ω_c the gain is 1/√2 ≈ 0.707 (−3 dB).

8 LP · step voltage input

For \( v_{in} = V\,u(t) \): the capacitor starts at 0 (a short), and at DC it becomes an open carrying the full source. The 4-step procedure gives the classic charging curve:

(5.3) \[ v_o(0^+) = 0, \qquad v_o(\infty) = V, \qquad \tau = RC \] \[ \boxed{\;v_o(t) = V\left(1 - e^{-t/\tau}\right)\;}, \qquad t \ge 0 \] Same exponential as Lecture 3’s RL step — the capacitor voltage is the star here.

9 LP · pulse and rectangular wave input

A pulse \( V_p[u(t) - u(t-t_p)] \) gives two intervals of the charging curve:

0 < t < tₚ (charging) \[ v_o(t) = V_p\left(1 - e^{-t/\tau}\right) \]
t > tₚ (discharging) \[ v_o(t) = V_p\left(1 - e^{-t_p/\tau}\right)e^{-(t-t_p)/\tau} \]
📏 Rule of thumb (slide): preserve the pulse shape

To pass a pulse with minimal distortion, choose \( \tau \) so the capacitor fully charges during the high interval — i.e. \( t_p \gtrsim 5\tau \) (large RC relative to the pulse width is the opposite error: the output barely rises).

Rectangular wave (slide exercise)

“Draw the output if the input is a 50% rectangular wave.” In steady state the capacitor oscillates between two levels, found exactly by the handoff rule from Lecture 4. With \( a = e^{-(T/2)/\tau} \):

\[ v_{o,\min} = \frac{aV}{1+a}, \qquad v_{o,\max} = \frac{V}{1+a} \qquad\Longrightarrow\qquad \text{tilt} = \frac{v_{o,\max} - v_{o,\min}}{(v_{o,\max}+v_{o,\min})/2} = \frac{2(1-a)}{1+a} \] Tilt quantifies the sag of a distorted rectangular output, in percent: tilt × 100%.

Small a (τ ≪ T/2) ⇒ big tilt (the LP output is a “rounded triangle”); a → 1 (τ ≫ T/2) ⇒ tilt → 0 (the output is an almost-perfect copy with only a tiny ripple).

10 LP as an integrator

When \( RC \) is very large compared with the time over which the input can make an appreciable change, the capacitor voltage changes so slowly that its drop is negligible compared to the drop across R — so essentially all of the input appears across R, and

(5.4) \[ i(t) = \frac{v_R}{R} \approx \frac{v_{in}}{R}, \qquad v_o = v_C = \frac{1}{C}\int_{0}^{t} i\,d\lambda \quad\Longrightarrow\quad \boxed{\;v_o(t) \approx \frac{1}{RC}\int_{0}^{t} v_{in}(\lambda)\,d\lambda\;} \] The LP circuit is an integrator in the large-RC limit. Condition: \( \tau = RC \gg T/2 \).
⚖️ The two limits side by side
  • HP, \( \tau \ll T/2 \) ⇒ differentiator: \( v_o \approx RC\,\dfrac{dv_{in}}{dt} \).
  • LP, \( \tau \gg T/2 \) ⇒ integrator: \( v_o \approx \dfrac{1}{RC}\int v_{in}\,dt \).

Both are “RC much larger or much smaller than the signal period” — the same number, two regimes. In between, the circuit just waveshapes.

11 The 3-dB cutoff, both ways

Both circuits share the same corner frequency; only the side of the band differs:

Circuit3-dB frequencyBehavior below ωcBehavior above ωc
High-pass RC lower cutoff: \( \omega_c = \dfrac{1}{RC} \) attenuates (−20 dB/dec slope) passes (gain → 1, phase → 0°)
Low-pass RC upper cutoff: \( \omega_c = \dfrac{1}{RC} \) passes (gain → 1, phase → 0°) attenuates (−20 dB/dec slope)

In hertz: \( f_c = \dfrac{1}{2\pi RC} \). At exactly ωc, |vo/vi| = 1/√2, i.e. the output power is half the input power — hence “3 dB”.

13 Summary

📌

• The HP RC (output across R) is a high-pass filter with lower 3-dB cutoff \( \omega_c = 1/RC \); step ⇒ \( Ve^{-t/RC} \); it blocks DC, copies edges, and decays to zero between edges.

• The LP RC (output across C) is a low-pass filter with upper 3-dB cutoff \( \omega_c = 1/RC \); step ⇒ \( V(1-e^{-t/RC}) \); pulses charge and discharge by handoff.

• HP differentiates when \( RC \ll T/2 \): \( v_o \approx RC\,dv_{in}/dt \).

• LP integrates when \( RC \gg T/2 \): \( v_o \approx \frac{1}{RC}\int v_{in}\,dt \).
